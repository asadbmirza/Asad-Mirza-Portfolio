# Portfolio Design Guidelines

## Direction

An editorial engineering portfolio built for recruiters and technical teams. The visual language is precise, architectural, and content-first: off-grid compositions, large grotesk typography, thin rules, and a single signal-green accent.

## Design Dials

- Design variance: 8/10
- Motion intensity: 4/10
- Visual density: 3/10

## Visual System

- Dark background: `#101210`
- Dark surface: `#171a17`
- Primary text: `#f1f3ec`
- Muted text: `#a8ada3`
- Signal accent: `#b7e45a`
- Light-mode background: `#eef0ea`
- Light-mode text: `#171a16`
- Light-mode accent: `#557619`
- Type: native system grotesk with a compact system monospace for technical metadata
- Radius: 14px, reserved for media and controls

## Composition

- Fixed 72px navigation with clear active states
- Hero fits the first viewport and uses an asymmetric copy-and-art composition
- Sections use generous vertical rhythm, oversized headings, and sparse rules
- About uses an open biography and facts rail
- Experience uses full-width accessible accordion rows
- Projects use one lead feature and a varied image gallery with titles outside media
- Skills use a generated systems artwork and open typographic matrix
- Education pairs degree information with architectural imagery and a facts rail
- Contact ends with one primary email action and a restrained link index

## Interaction

- Animate only opacity and transforms where possible
- Keep motion short, interruptible, and secondary to content
- Honor `prefers-reduced-motion`
- Use visible `:focus-visible` states and native semantic controls
- Keep all core information available without hover

## Image Direction

Use monochrome graphite architectural imagery with one signal-green plane or line. Generated assets should feel material and structural, not like dashboards, device mockups, or generic 3D decoration.
